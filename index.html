Claude CLI 브리지가 꺼져 있어요

Claude CLI 에 로그인되어 있어도, 웹 브라우저는 보안상 내 컴퓨터의 claude 를 직접 실행할 수 없습니다. ① 터미널(PowerShell·명령 프롬프트)에서 아래 명령을 실행하면 ② 브리지가 켜지고 http://127.0.0.1:8787 에서 이 앱이 자동으로 열립니다. 그 창에서 쓰세요.

npx -y github:samcho93/microbit-genius-agent

이미 실행했다면 아래 「로컬 주소로 열기」를 누르세요. 이 공개 주소(github.io)에서는 브라우저가 내 컴퓨터 주소 접근을 막는 경우가 많습니다 (Chrome 의 "로컬 네트워크 접근" 권한을 허용하면 여기서도 연결됨).

      사용할 LLM
      
      
      
      
      
    
      

    
      
      
      브라우저는 CLI 를 직접 실행할 수 없어서, 내 컴퓨터에서 작은 브리지를 켜 두면 웹앱이 그 브리지를 통해 claude 를 실행합니다. 터미널에서:
      
      
      npx -y github:samcho93/microbit-genius-agent
